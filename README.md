# 우울증 선별 진단 프로그램

환자의 상담 스크랩트를 분석하여 우울증 여부를 파악하는 AI 기반 진단 도구입니다.

## 🎯 목표

의사와 환자의 상담 스크랩트에서 우울증 지표를 자동으로 추출하고 점수를 계산하여 우울증 심각도를 분류합니다.

## 📊 기초 자료

### 1. 언어적 데이터 ✅ (사용중)
- **출처**: 의사-환자 상담 스크랩트
- **처리**: 자연어 처리를 통한 키워드 추출 및 문맥 분석

### 2. 신체적 데이터 ⏳ (향후 추가 예정)
- 신경호르몬 수치 (코르티솔, 세로토닌 등)
- 뇌파 데이터

### 3. 생활패턴 데이터 ⏳ (향후 추가 예정)
- 외출 빈도
- SNS 활동 빈도
- 수면 패턴

## 🔍 우울증 진단 메커니즘

### 1단계: 텍스트 전처리
```
원본 텍스트 → 유니코드 정규화 → 특수문자 제거 → 공백 정리 → 토크나이제이션
```

### 2단계: 키워드 추출 및 점수 계산
```
전처리된 텍스트 
    ↓
우울증 키워드 데이터베이스와 비교
    ↓
매칭된 키워드 발견
    ↓
점수 계산: 키워드 점수 × 카테고리 가중치 × 빈도수
```

### 3단계: 심각도 분류
```
총점 계산 (모든 카테고리 점수 합산)
    ↓
점수 구간에 따라 심각도 분류
    ↓
진단 결과 출력
```

## 📈 우울증 키워드 분류 (9개 카테고리) - 옵션 C 시스템

| 카테고리 | 가중치 | 중요도 | 예시 키워드 |
|---------|--------|--------|-----------|
| 🚨 자살 사상 | 3.0 | 극중요 | 죽고 싶다, 자살, 살 의욕 없음 |
| 😢 기분 저하 | 2.5 | 중요 | 슬프다, 절망, 우울하다 |
| 😒 흥미/즐거움 감소 | 2.0 | 중요 | 재미없다, 무관심, 무기력 |
| 😔 자책/죄책감 | 2.2 | 중요 | 내 잘못이다, 무가치하다 |
| 😴 수면 문제 | 1.8 | 중간 | 불면증, 잠을 못 자다 |
| 😫 피로/에너지 감소 | 1.8 | 중간 | 피곤하다, 기운 없음 |
| 🍽️ 식욕 변화 | 1.5 | 중간 | 식욕 없음, 체중 변화 |
| 🧠 집중력 저하 | 1.6 | 중간 | 집중 안 됨, 결정 불능 |
| 🎭 행동/신체 변화 | 1.4 | 중간 | 말 없음, 움직임 느림 |

### 점수 계산 공식
```
최종 점수 = 키워드 점수 × 카테고리 가중치 × 빈도수
총점 = 모든 발견된 키워드의 최종 점수 합계
```

## 📊 진단 결과 기준

| 점수 범위 | 심각도 | 설명 |
|----------|--------|------|
| 0-8점 | **정상** | 우울증 증상이 거의 없습니다. |
| 9-14점 | **경미** | 경미한 우울증 증상이 있습니다. 전문가 상담을 권장합니다. |
| 15-22점 | **중등도** | 중등도의 우울증 증상이 있습니다. 전문 치료가 필요합니다. |
| 23점+ | **심각** | 심각한 우울증 증상이 있습니다. 즉시 전문가 상담이 필요합니다. |

## 🚀 사용 방법

### 1. 설치

```bash
# Python 3.7 이상 필요
pip install -r requirements.txt
```

### 2. 프로그램 실행

```bash
python main.py
```

### 3. 메뉴 선택

#### 옵션 1: CSV 파일 분석 (대량 데이터)

```
메뉴에서 1 선택
→ CSV 파일 경로 입력 (기본값: data/sample_transcripts.csv)
→ 자동 분석 및 결과 저장
→ 요약 보고서 출력
```

**CSV 파일 형식:**
```csv
patient_id,date,counselor,transcript
P001,2026-05-01,Dr.Kim,"상담 스크랩트 텍스트..."
P002,2026-05-02,Dr.Lee,"상담 스크랩트 텍스트..."
```

#### 옵션 2: 단일 텍스트 분석

```
메뉴에서 2 선택
→ 상담 스크랩트 입력 (여러 줄 가능)
→ END 입력으로 종료
→ 상세 분석 결과 출력
```

### 4. 결과 확인

분석 결과는 다음 위치에 자동 저장됩니다:

```
results/
├── analysis_results.json      # 상세 분석 결과 (JSON 형식)
├── analysis_results.csv       # 결과 요약 (CSV 형식)
└── summary_report.txt         # 전체 요약 보고서 (선택사항)
```

## ⚙️ 프로그램 구성 요소

### `preprocessor.py` - 텍스트 전처리
- 유니코드 정규화 (NFKC)
- 특수문자 제거
- 연속 공백 제거
- 문장/단어 토크나이제이션

### `analyzer.py` - 우울증 분석
- 키워드 매칭 (정규식 활용)
- 점수 계산 (카테고리 가중치 × 키워드 점수 × 빈도수)
- 심각도 분류
- 상세 보고서 생성

### `classifier.py` - 배치 처리
- CSV 파일 로드
- 대량 데이터 분류
- JSON/CSV 결과 저장
- 요약 보고서 생성

### `main.py` - 사용자 인터페이스
- 대화형 메뉴
- CSV 분석 + 단일 텍스트 분석
- 결과 저장 옵션

## 🔬 기술 스택

- **프로그래밍 언어**: Python 3.7+
- **자연어 처리**: 표준 라이브러리 (re, unicodedata)
- **데이터 처리**: pandas, CSV, JSON
- **알고리즘**: 키워드 매칭 + 가중치 기반 점수 계산

## 📚 참고 기준

이 프로그램은 다음의 국제 진단 기준을 참고하여 설계되었습니다:

- **PHQ-9** (Patient Health Questionnaire-9): 임상 우울증 선별도구
- **DSM-5** (Diagnostic and Statistical Manual of Mental Disorders, 5th Edition): 정신장애 진단 기준
- **한국형 우울증 척도**: 한국 문화권에 맞는 우울증 지표

## ⚠️ 주의사항

1. **의료 대체 불가**: 이 프로그램은 진단 보조 도구이며, 의사의 진단을 대체할 수 없습니다.
2. **전문가 상담 필수**: 심각한 증상(자살 사상 등)이 감지된 경우 반드시 전문가 상담을 받으세요.
3. **데이터 정확성**: 입력된 상담 스크랩트의 정확성에 따라 분석 결과가 영향을 받습니다.
4. **프라이버시**: 환자 정보는 보안을 고려하여 관리되어야 합니다.
